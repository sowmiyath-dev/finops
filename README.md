# FinOps CUR Portal

AWS Control Tower Cost Management Web Application — built with **FastAPI + Next.js 14 + PostgreSQL**, deployed as Docker containers on EC2.

## Features

- **7 Control Towers** — onboard each management account (access keys or IAM role)
- **Sub-account discovery** — auto-discovers all accounts via AWS Organizations
- **Daily sync at 10:30 AM UTC** — cost data accurate up to 2 days prior
- **4 report types** — Account-wise, Service-wise, Resource-wise, Tag-wise
- **Full filter panel** — date range, accounts, services, regions, purchase types, tags, metric, granularity
- **CSV export** — direct download with all filtered data
- **MFA auth** — TOTP-based two-factor authentication
- **Role-based access** — owner / editor / viewer

## EC2 Deployment

### 1. Upload files to EC2
```bash
scp -i your-key.pem -r D:\finops-cur-dashboard ec2-user@YOUR_EC2_IP:~/
```

### 2. SSH and deploy
```bash
ssh -i your-key.pem ec2-user@YOUR_EC2_IP
cd finops-cur-dashboard
chmod +x deploy.sh
./deploy.sh
```

The script will:
- Install Docker + Docker Compose if missing
- Generate `backend/.env` from the example
- Build and start all containers

### 3. Configure backend/.env
```env
DATABASE_URL=postgresql+asyncpg://finops:finops_secure_pass@db:5432/finops_db
SECRET_KEY=<auto-generated>
FERNET_KEY=<auto-generated>
ADMIN_EMAIL=admin@yourcompany.com
PORTAL_ACCOUNT_ID=123456789012
```

### 4. Set NEXT_PUBLIC_API_URL for production
In `docker-compose.yml`, update:
```yaml
NEXT_PUBLIC_API_URL: http://YOUR_EC2_IP/api
```

### 5. Setup Nginx (optional, for port 80)
```bash
sudo yum install -y nginx   # Amazon Linux
sudo cp nginx.conf /etc/nginx/conf.d/finops.conf
sudo systemctl enable --now nginx
```

## AWS IAM Permissions Required

Attach to the IAM user or role used for each Control Tower:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ce:GetCostAndUsage",
        "ce:GetCostAndUsageWithResources",
        "ce:GetCostForecast",
        "ce:GetSavingsPlansUtilization",
        "ce:GetSavingsPlansCoverage",
        "ce:ListCostAllocationTags",
        "organizations:ListAccounts",
        "organizations:DescribeAccount",
        "sts:GetCallerIdentity"
      ],
      "Resource": "*"
    }
  ]
}
```

## Daily Sync Schedule

- Runs automatically at **10:30 AM UTC** every day
- Fetches last 7 days of cost data (accurate up to today − 2 days)
- Can also be triggered manually from the Control Towers page
